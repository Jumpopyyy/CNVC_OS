# 尽调工作台源码同步（2026-10-28）

本分支保留尽调工作台的本地开发更新，涵盖尽调清单、现场录音协同、数字分身构建、平台 Skill/智能体引用，以及近期已发布的界面调整。

## 最近更新

- 统一“补充你的需求”的文字、语音和材料入口；偏好默认只读，按需手动编辑。
- 建议需要明确采纳和保存；支持删除一轮问答、停止整理及对话修订校验。
- 右侧操作按钮统一尺寸与样式，Skill 区更名为“该分身沉淀的 Skill 库”。
- 专业起点支持多选；关注点合并去重，取消起点时保留其余起点需要的内容。保存的是关注点，等价组合可能显示“已涵盖”或自定义组合。
- 收尾现场协同的录音恢复、上传分片、纪要取消和插问交互，保留原有清单编辑与 Word 导出能力。

## 验证与边界

当前同步分支使用原尽调开发基线和原平台接口；没有复制正式服务器上其他模块尚未提交的权限、AI 助手及模型管理重构。数据库结构改动仅补充录音分片 JSON 的 TypeScript 描述，本轮不增加迁移，也不包含真实项目记录、录音、数据库、密钥或本机配置。

40 项定向测试、前后端类型检查和本地前端构建通过。模型请求在专项 UI 验证中使用合成响应，未以真实模型调用作为本次代码同步的验收。

GitHub 主线另有同事新增的全局分身导览、偏好问卷和动态头像。后续合并本分支时，需要保留这些主线功能，并对重叠的尽调页面与头像接口做兼容整合。该分支的推送本身不部署服务器，也不更新同事仓库的 main。
